Micapaint

[English] [日本語]

描き心地を追求した iPad 向けペイントアプリ

途切れた線でもはみ出さない「スライムブラシ」

ラフな線で囲まれた領域も滑らかに塗りつぶせる新発想のブラシ。癖になる感触です。

120fps 対応の高速なブラシ描画

GPU に最適化された描画エンジンで、1000×1000 ピクセルの混色ブラシも滑らかな動作。

シンプルで作業領域が広い UI

最小では端のツールバーだけ。便利さを損なわない限界まで UI を削ぎ落としました。

基本機能

  • 鉛筆、Gペン、水彩混色、ぼかし
  • 投げ縄塗りつぶし
  • メモリがある限り無制限なレイヤー数
  • レイヤーフォルダー
  • クリッピングマスク（もちろんフォルダーに対しても！）
  • キャンバス左右反転表示
  • 縮小キャンバスビュー
  • 透明度保護
  • フィルター（色相/彩度/明度、明るさ/コントラスト、トーンカーブ、ノイズ、ディザ、グラデーションマップ、ぼかし、色収差）
  • フィルターレイヤー（非破壊な調整レイヤー）
  • 見た目の明るさを保った彩度編集
  • 選択・移動
  • ゆがみツール（移動、拡大、縮小、回転、リセット）
  • 画像読み込み
  • PSD ファイル入出力
  • 標準的なブレンドモード
  • やり直し
  • 手ぶれ補正強度調整
  • バレルロール対応
  • ボタン数、配置をカスタマイズ可能なツールバー
  • 色履歴とスウォッチ
  • タイムラプス記録
  • [Pro] キャンバスの並べ替え
  • [Pro] ブラシのエクスポート・インポート

※ [Pro] 機能はアプリ内課金（買い切り）後に利用可能になります。
