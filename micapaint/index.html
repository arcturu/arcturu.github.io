Micapaint

[English] [日本語]

A painting app for iPad that pursues the ultimate drawing experience.

Slime Brush: Oozes in, Never out

A new take on the fill tool that smoothly fills areas enclosed by rough lines. The feel is addictive.

1000×1000 Blending Brush Runs at 120fps

A GPU-optimized rendering engine keeps even 1000×1000 px blending brushes running smoothly.

Simple, Workspace-first UI

At its most minimal, just a single edge toolbar. I've stripped the UI back as far as it can go without losing anything useful.

Basic Features

  • Pencil, G-pen, watercolor blending, blur
  • Lasso fill
  • Unlimited layers (as long as memory allows)
  • Layer folders
  • Clipping masks (yes, even for folders!)
  • Canvas flip for preview
  • Mini canvas view
  • Alpha lock
  • Filters (Noise, Hue/Saturation/Lightness, Tone Curve, Noise, Dither, Gradient Map, Blur, Chromatic Aberration)
  • Filter Layers (Non-destructive adjustment layers)
  • Selection & transform
  • Liquify (push, expand, pinch, rotate, reset)
  • Image import
  • PSD import / export
  • Standard blend modes
  • Undo / redo
  • Adjustable stabilizer strength
  • Barrel roll support
  • Customizable toolbar (button count & layout)
  • Color history and swatches
  • Timelapse recording
  • [Pro] Canvas reordering
  • [Pro] Brush export and import

* [Pro] features require a one-time in-app purchase to unlock.
